# Coding 1: Backup assignment — lists

You have ten minutes. This is an alternative to the pandas assignment, not an
additional assignment. It uses only a list, indexing, `len()`, and `print()`.

## Before you start: turn off AI

AI tools are not allowed in Coding 1.

Open this repository's folder in VS Code, not just `assignment.py`. The included
`.vscode/settings.json` disables built-in AI features and inline suggestions for
this workspace. Leave that file unchanged.

To check this, open Settings (`Cmd+,` on Mac or `Ctrl+,` on Windows/Linux), select
the **Workspace** tab, search for `chat.disableAIFeatures`, and make sure
**Chat: Disable AI Features** is checked. This disables the built-in Copilot
features; disable any other AI extensions separately through the Extensions view
using **Disable (Workspace)**. Do not use external AI tools either.

See the [VS Code instructions for disabling AI features](https://code.visualstudio.com/docs/setup/copilot#disable-ai-features).

## Task

Read `assignment.py`. Answer its two numbered questions by adding short Python
comments beginning with `#` below each question. Predict the results before
running the code. Explain your reasoning in your own words.

Do not change the Python code. Running it afterwards to check your answers is
optional; no packages or data files are required. Use your existing Python setup,
or run `uv run python assignment.py` from this repository's folder if you have uv.

## Submit your comments

1. Fork this repository to your own GitHub account.
2. Clone **your fork** onto your computer and open its folder in VS Code.
   For a new fork, use `git clone`, not `git pull`.
3. Add your answers to `assignment.py` and save it.
4. In the terminal inside this repository's folder, run:

   ```bash
   git add assignment.py
   git commit -m "add comments"
   git push
   ```

5. Visit your fork on GitHub and check that your comments are visible before
   leaving class. You do not need to open a pull request.

## Marking

- **2**: comments correctly answer both numbered questions.
- **1**: comments correctly answer one numbered question.
- **0**: no timely commit or no substantive comments.
